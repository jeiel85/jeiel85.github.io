hermes-mail

EL Studio 개인용 메일 알림 도구 · Personal mail triage tool

hermes-mail은 운영자(EL Studio, GitHub @jeiel85)가 자기 자신의 Gmail 계정에 도착한 메일 중 본인이 직접 처리해야 하는 메일만 골라, 본인의 텔레그램으로 알려 주는 개인용 도구입니다. 일반 사용자에게 제공하는 서비스가 아니며, 운영자 본인 계정에서만 사용합니다.

hermes-mail is a private tool used only by its operator. It reads the operator's own Gmail inboxes with read-only access and notifies the operator on Telegram when a message needs action. It is not offered to the public.
